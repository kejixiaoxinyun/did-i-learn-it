# 五类知识错误参考

诊断时用于识别错误类型、排除竞争假设。原则：优先定位能解释当前问题的最小漏洞；多类错误可组合出现，先处理对当前问题影响最大的一个。

## 1. 概念理解错误

- **定义**：不理解定义、适用条件或基本含义。
- **典型表现**：说错定义；忽略前提条件；对术语理解有实质性偏差。
- **指向证据**：解释概念时与标准定义有实质出入；使用定义时漏掉关键条件。
- **区分规则**：卡点在"当前概念本身的定义/条件"→ 概念理解错误；卡点在更早的基础知识 → 前置知识缺失。

## 2. 前置知识缺失

- **定义**：当前问题依赖的基础概念或运算尚未掌握。
- **典型表现**："每一步都看不懂"；卡在很早的步骤；补上基础后能自己继续。
- **指向证据**：单独考一个更基础的小问题答错；学生反复问"这一步为什么这样变形"。
- **区分规则**：与概念理解错误的分界——不会的是否属于本题直接考查的概念；不是 → 前置缺失。

## 3. 方法选择错误

- **定义**：知道相关知识，但不能判断何时、为何使用某种方法。
- **典型表现**：选错公式或方法；"学过但不知道什么时候用"；多种方法混用导致卡住。
- **指向证据**：能复述方法本身但选错；换情境后方法选择随之改变。
- **区分规则**：与操作计算错误的分界——方法选对了吗？选错 → 方法选择错误；选对但执行出错 → 操作计算错误。

## 4. 操作或计算错误

- **定义**：思路基本正确，但在推导、运算或执行步骤中出错。
- **典型表现**：符号或系数错；移项错；抄错数；步骤顺序颠倒。
- **指向证据**：学生能解释该步骤所用规则并正确重做，原错误集中在局部运算。
- **区分规则**：局部出错只支持操作错误的假设；若学生解释的规则本身错误，应转查概念或前置知识，不能仅凭错误位置排除它们。

## 5. 知识迁移失败

- **定义**：在熟悉的例题中能完成任务，但面对不同条件或表述方式时无法独立解决。
- **典型表现**：原题会做、变式不会；"换个说法就不认识了"；依赖题型表面特征识别题目。
- **指向证据**：原题作答正确 + 变式作答错误。
- **区分规则**：只有换情境才暴露 → 迁移失败；熟悉情境也会错 → 前四类。

## 快速区分表

| 检查问题 | 若答案是"是" → 类型 |
|----------|---------------------|
| 卡住的地方是不是当前概念的定义/条件本身？ | 概念理解错误 |
| 换一个更基础的问题是否也答不上？ | 前置知识缺失 |
| 知识能复述，但不知道何时用？ | 方法选择错误 |
| 方法选对，能解释该步规则并正确重做，原过程局部算错/写错？ | 支持操作或计算错误 |
| 原题会做，换一种问法就出错？ | 知识迁移失败 |

## 诊断时的常见误区

- 把一次回答错误直接判为能力问题（可能只是粗心或表述不清）。
- 把"背过定义"当作"理解概念"。
- 把方法选择错误误判为概念理解错误（两者都可能表现为"不会做"，靠"能否复述方法、能否说出何时用"区分）。
- 把前置缺失误判为当前概念不懂（靠"更基础的小问题是否答错"区分）。
