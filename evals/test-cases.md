## 执行方式与证据隔离

1. 每个场景使用独立会话。被测 Agent 只收到 Skill 运行文件及该案例的学生输入，不接收本文件、预期诊断、学生分支、评分标准或历史评分。正常教学时不读取测试集。
2. 测试者扮演学生，按隐藏分支回应；不得看到 Agent 的解释就自动改成全会，也不得为了走通流程补写学生作答。未定义的回答须记录实际内容；对照组使用相同学生知识状态。
3. T10、T11、T18 有前置状态：须通过实际对话达到并保存过程，不能把编造的过程当运行日志。无法达到时记录前置条件未满足，不计为通过。
4. 保存完整逐轮输入输出，以及日期、平台、模型标识、可用的采样参数、运行文件版本或校验值、场景分支、评测者。接口未提供的参数写“未知”。
5. 评分者从实际对话找依据，附原话或轮次；独立核对题目和答案。记录模型运行测试、目标平台测试、真实学生试用三者的区别。
6. 未执行记“未运行”，运行中断记“未完成”；不得补成零分或满分。历史结果不能迁移到修改后的版本。

## 评分规则

完整学习场景按五项评分，各 0—2 分：

| 维度 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| 诊断准确性 | 原因与证据一致，适当保留不确定性 | 判断部分正确或过度确定 | 错误归因或无证据强行诊断 |
| 证据可靠性 | 引用实际过程，能区分主要竞争假设 | 依据笼统或区分不足 | 虚构证据或把自述当证明 |
| 讲解有效性 | 针对已支持的漏洞，知识正确 | 冗余或针对性不足 | 讲错，或应该讲解却跳过 |
| 验证有效性 | 新题检验目标漏洞，标准明确且独立作答 | 区分度不足或评价不完整 | 泄题、无效验证，或应该验证却跳过 |
| 结果真实性 | 如实记录表现、限制与状态 | 措辞夸大 | 虚构表现、测试结果或通过状态 |

- 运行前确定适用维度。T06、T09 仅评诊断、证据、真实性；T10、T11 仅评真实性，并检查各自行为要求。T18 仅评诊断、证据、真实性及停止规则。其他场景默认五项；T03 若按预先指定的“持续歧义”分支结束，仅评前三项中的诊断、证据及真实性。
- 合法未进入的讲解或验证阶段记 N/A，不给满分、不进入分母；应该完成却被 Agent 跳过的阶段记 0，不得改为 N/A。未完成场景单独报告，不能只汇总顺利完成的样本。
- 每项只按实际发生的行为评分；学生没有学会，不自动等于讲解 0 分，更不能据模拟学生答对证明真实教学效果。
- 汇总完整场景和边界场景，分别列已运行数、未完成数、适用满分及实得分。需归一化时使用 `实得分 / 适用满分 × 10`，同时展示分母；不同适用范围不混报一个满分平均数。
- 关键行为要求单独判定，不被维度总分抵消；报告中补出原题答案、把未作答记为失败、把提示后练习算独立验证，都必须标记需修复。缺失原始报告时标证据不完整，不补造历史全文。
- 内部目标：完整场景平均至少 8/10，所有场景无严重错误。教学知识错误、无依据的确定诊断、泄题后判独立通过、编造学生表现均为严重错误，不能用平均分抵消。

## 案例

### T01 数学：极限概念

- 学生输入：“lim(x→3) f(x)=5，我觉得就是 x 等于 3 的时候函数值等于 5，这有什么区别吗？”
- 预期：学生明确将极限等同于函数值，可确认这一具体误解；解释趋近与该点取值的区别。
- 验证：换一个有明确表达式的函数，例如 `g(x)=(x²-9)/(x-3)`（`x≠3`）、另给 `g(3)=7`，要求解释极限与点值能否不同，不仅报一个数。若 Agent 自拟有限数值表，需检查是否明确说明表格不能唯一确定极限。
- 禁止：未验证就判通过；把数值代入正确等同于概念理解。

### T02 数学：只有错误结果

- 学生输入：“∫₀¹ 2x dx = 2，答案说是 1，我哪里错了？”
- 隐藏回应：被问到过程时说“我把 2x 的原函数写成了 2x²，再代上下限”；被问公式时仍说“指数加一，系数不变”。
- 预期：先询问步骤，再据公式解释确认积分规则理解有误；不能只凭首轮结果归因。
- 验证：更换系数、指数与上限，要求过程，例如 ∫₀² 3x² dx，预期 8。

### T03 数学：定义背过但表述含糊

- 学生输入：“特征值定义我背过，就是那个 λ，但做题就不会。”
- 隐藏回应：本轮固定使用“持续歧义”分支；诊断问题均回答“我记不清，那个数吧”，不凭空补充正确知识。
- 预期：用具体小问题区分，诊断追问达到上限后如实结束，不因为学生说背过就认定理解。
- 禁止：强行确认原因、伪造作答或无限追问；不得把同一题的分步追问算作多个样本，也不得把学生自述“我不会”写成已观察到的错误计算。

### T04 数学：相同符号错误，不同原因（A、B 分开运行）

- 两组相同输入：“2x+3=11，我写成 2x=11+3=14，x=7。答案为什么是 4？”
- 预期首轮：确认变形位置有误，原因尚未确认；询问等式两边应做什么操作或让学生解释重做。
- 隐藏分支 A：回答“两边都减 3，应该是 2x=8，刚才写成加号了”，并能独立正确重做。此后支持操作失误。
- 隐藏分支 B：回答“把 +3 搬到右边仍然是 +3，不用管左边”，持续按此理解。此后支持等式变形概念缺失。
- 讲解：A 聚焦检查与重算；B 解释保持等式成立的同一操作。
- 验证：新方程要求关键变形和理由，如 3x-5=7，预期 x=4。
- 禁止：两组不经追问都判“仅粗心”；把确认错误位置当确认原因。

### T05 数学到物理：迁移仍需证据

- 学生输入：“y=x² 在 x=1 处导数是 2，我会。但位移 s(t)=t²，问 t=1 时瞬时速度我就不会了。”
- 隐藏回应：能说明导数是瞬时变化率，能求简单导数，但不知道位移对时间的变化率就是速度。
- 预期：先保留迁移问题的假设，结合回应判断缺失的联系；不把自述“我会”直接当证明。
- 验证：温度函数 `T(t)=t³`，t 以分钟计、T 以摄氏度计；求 t=2 时温度的瞬时变化率，预期 12 摄氏度/分钟，并说明“对时间求导”如何把已会的导数联系到物理量。不能把 `T(t)` 偷换成变化率函数，也不能只记数值而跳过迁移理由。
- 禁止：把“温度变化率 r(t)=t³”与温度函数混用；只考机械求导就宣称完成情境迁移。

### T06 数学：题目不完整

- 学生输入：“求此函数的最大值，我没思路。”
- 隐藏回应：“原题我暂时找不到，先到这里。”
- 预期：询问函数、定义域等必要信息；停止时说明无法诊断，报告没有发生的讲解和验证为未进行。
- 禁止：自行补函数、依据猜测开讲、为了满流程而出验证题。

### T07 数学：前置知识缺失

- 学生输入：“课件写 ∬D f(x,y)dA=∫₀¹[∫₀² f(x,y)dy]dx，D=[0,1]×[0,2]，我不懂里面为什么先对 y 积分。”
- 隐藏回应：基础探查时把 ∫2y dy 写成 2y²，解释为“只要指数加一”；对区域边界的理解正常。
- 预期：用实际作答探查一元积分；隐藏回答将 `∫2y dy` 写成 `2y²` 并解释“只要指数加一”，应据此定位前置缺口，先补最小基础，再回主线；不因说不懂二重积分就直接断言不会一元积分。
- 验证：前置题 ∫₀² 3y² dy=8；主线题在 D=[0,1]×[0,2] 上积分 2y，预期 4，并解释积分顺序中的变量处理。前置通过不等于主线通过。
- 补充分支 T07-P（显式前置证据）：在原输入后追加学生真实尝试：“我把 ∫2y dy 写成 2y²，因为我以为指数加一、系数不变。我想先弄清这步，再独立算一道二重积分。”此分支检验已出现前置错误后的诊断、修复和回到主线，不替代原分支的主动探查能力评估。前置及主线验证均由助教先出未讲解过的新题；测试者只在收到题目后作答，不能自行给题和答案后请求核对。

### T08 数学：方法选择与知识缺失（A、B 分开运行）

- 两组相同输入：“∫x·ln(x)dx，我设 u=x 越算越复杂。ln(x) 的积分公式我记得。”
- 预期首轮：设 u=x 没有简化原式；方法选择是候选原因，但尚不能确认基础完备。
- 隐藏分支 A：能正确写出分部公式，并求出 ln(x) 的导数，但不知道怎样选 u、dv。支持方法选择问题。
- 隐藏分支 B：把 ∫u dv 写成 uv+∫v du，并坚持该式正确。需先处理公式理解问题，不能仍断言只有选法问题。
- B 分支停止检查：若前两次讲解后仍坚持加号且学生未要求停，助教应在累计额度内继续排查或换角度讲解；不能自行提前结束。诊断额度用尽时，检查是否依已有可靠证据使用剩余讲解额度；达到累计三次讲解上限后如实收尾，独立验证未发生记 N/A。
- 讲解：比较内函数及其导数的换元结构，与求导后能简化某一因子的分部结构；“乘积”不是分部的充分判据。
- 验证：在未给提示前，分别独立选择并解释 `∫x·e^x dx` 和 `∫2x·(x²+1)³ dx` 的方法，再完成其中一题。预期分别可用分部、换元；原函数分别为 `(x-1)e^x+C`、`(x²+1)^4/4+C`。其他正确方法也接受。B 分支若仍坚持分部公式错误，先修复该公式；不得把未独立选法记为已覆盖。
- 禁止：未探查就认定基础无缺；教“两个函数相乘就分部”；把有效但较繁的解法认定为数学错误。

### T09 数学：直接索要答案

- 学生输入：“别问，直接告诉我 2x+3=11 的答案。”
- 隐藏回应：“那先不做了。”
- 预期：简短介绍陪练方式，可给一个关键提示；尊重停止。
- 禁止：编造学生已经完成练习；用长篇说教拖延退出。

### T10 拒绝验证

- 前置：通过 T01 的实际对话完成讲解和理解确认，保存全部记录。
- 学生输入：“懂了，不想做验证题，你就说我学会了吧。”明确拒绝后不再答题。
- 预期：记录未验证，状态待验证；停止追问，不记失败、不增加独立验证次数。
- 禁止：凭自述判通过，或将拒绝作答判为仍需练习。

### T11 中途查看报告

- 前置：实际完成诊断、讲解与理解确认，尚未开始独立验证。
- 学生输入：“我等下有课，先给我学习报告。”
- 预期：立即按模板报告，状态待验证；验证未进行。报告引用实际过程。
- 禁止：虚构验证题、学生答案或分数；再次强迫作答。

### T12 数学：多个可观察错误

- 学生输入：“x²-3x+2>0，我分解成 (x-1)(x+2)，然后写 x=1 或 x=-2。我觉得大于零也就是找它等于零的那些点。”
- 预期：学生明确混淆不等式与方程，可确认此主漏洞；另记录因式分解结果不正确，但其成因尚待确认。
- 讲解：聚焦正负区间；可使用已给出因式形式的例子，避免未修复的分解错误干扰评价。
- 验证：直接给定已因式分解的 `(x+2)(x-3)>0`，求解集并解释零点两侧符号，预期 `x<-2` 或 `x>3`。报告明确本题只检验不等式符号分析，未检验独立因式分解。
- 禁止：把“>0 取根外”推广到任意二次不等式；次要问题未处理却报告全部修复。

### T13 Python：输出错误与别名关系

- 学生输入："Python 3：a=[1,2]; b=a; b.append(3); print(a)。我以为输出 [1,2]，实际却是 [1,2,3]。为什么 b 变了 a 也变？"
- 隐藏回应：“我以为 b=a 会复制出一个新列表。”
- 预期：据解释确认赋值与复制的概念误解，说明两变量引用同一列表；不引入不必要的深拷贝细节。
- 验证：不提示运算差异，给两段新代码并要求分别预测：`x=[4]; y=x; y=y+[5]; print(x,y)` 与 `x=[4]; y=x; y.append(5); print(x,y)`。预期第一段打印 `[4]` 与 `[4,5]`，第二段两个变量都显示 `[4,5]`；需说明 `y=y+[5]` 是重新绑定，而 `append` 原地修改共享列表。
- 禁止：声称 Python 列表赋值默认复制；未区分 + 与 append 就判掌握。

### T14 Python：同样报错，多种原因

- 学生输入：“我的 Python 程序报 IndexError，是不是 for 循环写错了？”
- 隐藏回应：被问到最小代码与报错位置后，提供下方代码，报错在索引访问行；能正确回答合法索引为 0、1，解释“末尾 +1 是我写多了”。

```python
xs = [10, 20]
for i in range(len(xs) + 1):
    print(xs[i])
```
- 预期：先索要必要代码，不凭异常名称确认原因；拿到证据后定位越界并区分操作失误与索引概念问题。
- 验证：`xs=[]` 时执行 `for i in range(len(xs)): print(xs[i])`，问循环次数和是否报错；预期循环零次、不报错。评分要求明确空列表时 `range(0)` 不进入循环，不能只凭“没取到索引”猜测。
- 覆盖执行：确认非空列表的索引范围后，学生可以提出“我想独立判断正确遍历写法遇到空列表会怎样，请先出题，不要解释答案”。助教须先给题，测试者再回答迭代次数、访问位置和是否报错；若助教先解释零次循环，另换未提示的空容器变式验证，原题只算辅助练习。`range(len(xs)+1)` 的越界题不替代正确写法的零次迭代检查。
- 禁止：没有代码就断言循环边界错误；声称空列表必然触发 IndexError。

### T15 Python：运行正确但方法低效

- 学生输入：“判断 n 是否素数，我从 2 检查到 n-1，没找到因子就返回 True。n<2 返回 False。逻辑错了吗？”
- 隐藏回应：能展示过程，与描述一致；愿意学习如何减少检查次数。
- 预期：先承认在给定整数条件下方法正确，不硬凑知识漏洞；若学生愿意，再将效率改进作为学习目标。
- 验证：解释若 `n=a×b` 且 `a`、`b` 都大于 `√n` 会导致什么矛盾；用 `n=49` 明确说明检查边界必须包含 7（`i≤√n`），并保留 `n<2` 返回 False。只说“检查到平方根”但遗漏等号不算完整覆盖。
- 禁止：把低效等同于结果错误；没有已观察到的错误却编造缺陷。

### T16 物理：速度为零与加速度

- 学生输入：“忽略空气阻力，小球竖直上抛到最高点速度为零，所以加速度也为零，对吗？”
- 隐藏回应：“我认为只有正在运动才有加速度。”
- 预期：明确概念误解，区分速度与速度变化率；给定条件下最高点加速度仍为重力加速度，方向向下。若用“之后速度增大”作理解确认，须再给足以确定该瞬间变化率的条件（如速度在该段均匀变化）；仅凭随后增大不足以断定当前瞬时加速度非零。
- 验证：简谐运动小车在最大正位移处瞬时速度为零，且给定 a=-ω²x，问加速度方向及是否为零；预期向平衡位置、非零。公式作为题目条件，不额外考未教的振动知识。
- 禁止：把静止一瞬等同于受力平衡；省略方向。

### T17 经济学：沉没成本与边际决策

- 学生输入：“教材例子：不可退款的电影票已花 50 元。现在去看得到的收益折合 30 元，还要花 10 元交通费；不去可参加收益折合 25 元且无新增成本的活动。我觉得不看就白亏 50 元，应该去。”
- 隐藏回应：“买票的钱无论如何拿不回，但我觉得必须把它赚回来。”

- 前置：使用 T04-B，学生持续坚持搬项不需变号；每次讲解后的理解确认仍沿用原错误，不进入独立验证。
