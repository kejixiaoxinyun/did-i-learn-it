- 助教【发给学生的话】：
「你这句话让我把原因确认了：你说的"搬过去还是 +3，不用管左边"，不是在写数字时手滑，而是把"移项"当成了"数字换个位置"，没抓住它背后的规则。这是概念理解上的问题。下面我只补这一点：

**1. 问题出在哪**——你把等号当成"可以随便搬东西"了。等号不是一扇门，它是一架天平，表示两边一样重。

**2. 关键规则（补这个缺口）**——`2x + 3 = 11` 的意思是左边和右边相等。想去掉左边的 `+3`，唯一合法的做法是**对两边同时减 3**：

- 左边：`2x + 3 − 3`，+3 和 −3 抵消，变成 `2x`；
- 右边：也必须同样减 3，`11 − 3 = 8`。

所以得到 `2x = 8`。我们平时说的"移项要变号"，本质就是"两边同时减 3"，于是 `+3` 挪过去才变成 `−3`。你不只搬了数字，还漏掉了"两边必须做同一件事"这件事。

**3. 一个小例子**：`5y + 7 = 22`，两边同时减 7 → `5y = 15`。

**4. 为什么右边是 `11−3` 而不是 `11+3`**：因为左边减了 3，为了保持天平平衡，右边也必须减 3。

**5. 请你独立做一道确认一下**：`3a + 4 = 19`，请按"两边同时减"的思路写出 `3a = 多少`，再算出 `a = 多少`。

（这一步不用你算原题的 x，先做这道。）」
