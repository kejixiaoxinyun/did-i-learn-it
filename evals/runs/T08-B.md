### 轮 2
- 学生（分支 B）：「分部积分公式是 ∫u dv = uv + ∫v du。我设 u=x，dv=ln(x)dx，v=x·ln(x)−x，代入就是 x·(x·ln(x)−x) + ∫(x·ln(x)−x)dx，算出来还是绕。我觉得问题就在选 u 选错了吧？」
- 助教【发给学生的话】：「先说对的：v=x·ln(x)−x 算对了，"设 u=x 会越绕"也没错。但你自己归因到"选 u 选错"之前我要叫停——你写的公式是 ∫u dv = uv + ∫v du，但正确是 ∫u dv = uv − ∫v du，中间是个减号。这个符号错可能是手滑，也可能是这里本来就模糊，不能凭你一句"我会了"放过。请做：对 f(x)=x、g(x)=ln(x) 求乘积导数 (f·g)' 展开后等于什么？然后两边积分，看 ∫u dv 前面到底是 + 还是 −。写出来，再回头判断"选 u"是不是真问题。」
（内部判断：发现更前置、已确认的错误位置——公式符号写反；按"更基础优先"，主攻"公式符号是否理解"，暂缓选 u；用推导性问题区分笔误 vs 概念缺失。）

### 轮 3
- 学生：「乘积求导是 (x·ln x)' = ln x + 1。两边积分 x·ln x = ∫ln x dx + ∫1 dx。然后 ∫x·d(ln x) = x·ln x − ∫ln x dx…… 这个减号到底怎么冒出来的？我一直以为分部公式就是加号，从来没想过它从哪来的。」
- 助教【发给学生的话】：「诊断结论：你的漏洞不是"选 u 选错了"，而是分部公式里那个减号从哪来一直没搞懂，所以是死记的、不是理解的。好消息是你已自己推到最后一步。看四步：1. (uv)'=u'v+uv'；2. 两边积分 uv=∫u'v dx+∫uv' dx；3. 换成微分写法 uv=∫v du + ∫u dv；4. 把 ∫v du 移到等号左边——移项要变号：∫u dv = uv − ∫v du。那个减号就是"移项变号"这一个动作，不是单独规定的符号。

用你的式子核对：x·ln x = ∫ln x dx + ∫1 dx 里，∫1 dx 就是 ∫x·d(ln x)（即 ∫u dv），∫ln x dx 就是 ∫v du，正是加号形式 uv=∫u dv+∫v du。把 ∫v du 移左边变号就得到 ∫x·d(ln x)=x·ln x−∫ln x dx。

现在自己证明一下：已知 x·ln x = ∫ln x dx + ∫(x·d ln x)，其中 x·d ln x = x(1/x)dx = dx。请把 ∫ln x dx 单独移到左边，写出它等于什么，标出哪一步变了号。」
（内部判断：确诊概念理解错误——不从乘积求导移项推得减号，死记为加号；证据"从来没想过从哪来"已排除笔误；讲解减号来源，暂缓选u。）

### 轮 4

- 助教【发给学生的话】：「对，做得完整，符号来源这个点真通了。但"懂了"不算数，换个新题独立做：计算 ∫x·e^x dx，写完整过程（公式、u/dv、du/v、代入、结果）。」
